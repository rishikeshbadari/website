# Gallery

A minimal static photo gallery.

## Structure

```text
.
├── index.html
├── css/
│   ├── base.css
│   └── gallery.css
├── js/
│   └── gallery.js
├── data/
│   └── gallery-data.js
├── pictures/
│   ├── optimized/
│   └── thumbs/
└── vercel.json
```

## Local Development

No build step is required.

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
